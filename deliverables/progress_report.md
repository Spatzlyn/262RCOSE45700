## 3. 현황 및 데이터 수급 제약 사항 (중요 보고)

### [AI Hub 71784 접근 제한 이슈]
- **현상**: 데이터 담당자(한태문)의 외국인 신분으로 인해 통신사/I-PIN 본인인증이 불가능하여 AI Hub 공식 포털을 통한 원천 대량 데이터셋(1.2TB) 다운로드 신청이 차단됨.
- **조치 현황**: PM 윤유경 님께 상황을 신속히 공유하였으며, 1차적으로 GitHub `dry_run_v1` 브랜치의 고품질 샘플을 활용하여 벤치마크 방법론 검증을 차질 없이 진행함.
- **협조 요청**: 추가 대량 데이터셋 확보를 위해 **팀 내 한국인 팀원(PM 또는 팀원) 명의로 AI Hub 데이터 신청 및 다운로드 지원이 필수적임**.

### [3장 전방 샘플 확보 진행 현황: 미완료]
- **현황 기록**: `3장 전방 샘플 확보: 미완료 / AI Hub 접근 제한 및 추가 소스 확인 필요`
- **사유**: 현재 `kakao_dryrun`에 업로드된 4장의 이미지는 서로 다른 3개의 전방 시퀀스가 아니라 **동일 차량의 4방향 시야(F, B, L, R)로 이루어진 단일 Source Group**입니다.
- **데이터 원칙 준수**: 데이터 누수(Data Leakage)를 방지하고 학술적 엄밀성을 지키기 위해, B/L/R 이미지를 억지로 전방 샘플 3장으로 둔갑시키지 않고 **현재 가용한 전방 이미지는 `view_F.png` 1장임을 솔직하고 명확하게 기록**하였습니다. 나머지 2개 이상의 독립 전방 시퀀스는 한국인 계정을 통한 AI Hub 추가 샘플 확보 직후 신속히 보완할 예정입니다.
