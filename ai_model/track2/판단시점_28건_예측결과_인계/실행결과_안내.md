# Track 2 판단 시점 28건 예측 결과

영상 4건의 판단 시점별로 후보 보행자 선택과 위치 예측을 각각 수집했습니다. 두 과제는 독립적으로 실행했습니다. 선택에는 번호 표시 프레임을, 위치 예측에는 마지막 원본 프레임을 사용했습니다.

- `predictions.jsonl`은 문항당 한 줄입니다. `target_id`는 해당 시점의 후보 번호이고, `bbox_xyxy`는 마지막 원본 프레임의 픽셀 좌표 [왼쪽, 위쪽, 오른쪽, 아래쪽]입니다. 판단 시각은 초 단위이며 프레임 인덱스는 0부터 시작합니다.
- `문항별_예측_및_출처.csv`에서 각 문항의 두 예측값, 각각의 서버 출처, 원문·검증 파일 경로와 SHA-256을 확인할 수 있습니다. 서버 출처의 기준 디렉터리는 `/home/ubuntu/infer/`입니다.
- `outputs/<item_id>/`에는 원시 디코딩 응답과 검증 기록이 과제별로 있습니다. 최초 실행과 보완 실행에서 유효한 응답을 과제별로 모았으며 좌표를 자르거나 응답 형식을 수정하지 않았습니다.
- 28건 모두 선택 ID가 해당 후보 목록에 포함되고 예측 상자가 원본 이미지 범위 안에 있습니다. 이는 출력 형식과 값의 유효성 검증입니다. 대상 선택 정확도 및 Box IoU는 검수 GT로 별도 채점해야 합니다.
