# Track 2 영상 입력 및 실행 방법

대상은 태문님이 선정한 영상이다. 각 영상에서 같은 판단 시점에 두 번 독립적으로 질의한다. 선택 질의에는 후보 전체에 중립적인 번호를 표시한 마지막 프레임을 사용한다. 위치 질의에는 번호와 박스가 없는 원본 마지막 프레임을 사용한다. 위치 결과는 원본 해상도의 픽셀 좌표 [x1, y1, x2, y2]다.

## 준비물
- 원본 영상, 첫 표시 프레임부터 잰 판단 시점(초), 그 시점의 번호 표시 이미지, 후보 번호 목록.
- 표시 이미지가 실제 마지막 입력 프레임과 같은 장면·시점인지 사람이 확인한다. 코드는 해상도 일치를 검사한다. 정답 대상 ID, 정답 박스, 최초 충돌 시점은 채점용으로 따로 관리한다.
- Python 3.11, PyAV(av), Pillow, CUDA 사용이 가능한 PyTorch, Transformers(Gemma4 클래스 지원), bitsandbytes 및 accelerate. 팀의 기존 vlm 환경과 검증된 google/gemma-4-E4B-it 로컬 가중치를 사용한다. 모델 revision은 4ecc2ba63bcac23ba4a767fc87025b1450f84c9c이다. 실행자는 지정한 폴더가 해당 snapshot인지 확인한다.
- 이 폴더의 스크립트와 한글 프롬프트를 함께 둔다. 아래 예시는 저장소 루트에서 실행하며 경로·시점·후보 번호는 실제 전달값으로 바꾼다.

## PowerShell 예시

```powershell
conda activate vlm
$runner = '.\ai_model\track2\run_track2.py'
$inputs = @('--video','D:\private\clip01.mp4','--decision','1.4','--numbered-key','D:\private\clip01_numbered.png','--ids','1','2','3','--out','D:\runs\clip01_first')
python $runner @inputs --check-only
# 실제 추론 시 새 출력 폴더 이름과 로컬 모델 경로를 확인한 뒤 실행
python $runner @inputs --model-dir 'D:\models\gemma-4-E4B-it\4ecc2ba63bcac23ba4a767fc87025b1450f84c9c'
```

입력 확인 모드는 영상과 번호 이미지를 읽고 프레임 수·해상도·마지막 입력 시각을 출력한다. 판단 시각 이하의 프레임을 약 0.2초 간격으로 고르고 마지막으로 관찰 가능한 프레임도 포함한다. 영상이 길수록 입력 프레임 수와 GPU 메모리 요구량이 커진다.

## 결과 확인
새 출력 폴더에 input_record.json(입력 해시, 후보, 시각, 해상도), select_raw.txt와 box_raw.txt(디코딩된 첫 응답), select_validation.json과 box_validation.json이 생성된다. 기존 출력 폴더는 덮어쓰지 않는다. 실행이 중단된 경우 남은 파일을 보존하고 다시 시도할 때는 새 폴더를 사용한다.

valid는 후보 번호 포함 여부 또는 박스 좌표 범위에 관한 검사다. 선택 정확도와 Box IoU는 백엔드에서 검수된 정답과 대조한다. 두 질의는 독립적이므로 선택 번호와 위치 박스가 동일한 보행자를 가리키는지도 분석 시 확인한다. 이 제출본의 실제 영상 GPU 추론은 미실행 상태다.
