# 백엔드 채점 전달 안내

담당 하경흠. 현재 상태는 로컬 전달 자료 준비 완료이며 외부 발송은 하지 않았습니다.

## 전달 내용

backend_handoff에 pilot_001부터 pilot_006의 전체 prediction JSON, raw 생성 텍스트와 decoded 텍스트를 각각 6개씩 보관합니다. 예측 JSON은 원 parsed_output과 기존 전달 JSON에 바이트 단위로 같습니다. raw/decoded도 원본을 그대로 복사했습니다. 모델 출력 자체를 고치거나 필드를 채우지 않았습니다.

run_metadata.json은 실제 config/status/input_audit/validation 기록에서 비공개 절대경로를 제외한 파생 전달 기록입니다. 원 config.json을 덮어쓰지 않았으며 원 파일별 SHA-256을 함께 제공합니다. 이미지 대신 item_id와 이미지 SHA-256으로 연결합니다. 전용 VRAM 실측이 검증된 자료로 해석하지 않습니다.

## 백엔드에 요청할 결과

- sample_id / GT와 예측 차이 / 실패 단계 / 확인 근거 / 다음 개선 작업.
- 실패 단계는 형식, 객체·영역 인식, 근거 연결, 관계 판정, 대응 적용으로 구분합니다.
- canonical Schema·Action 규칙·reference 버전과 검수 상태, 각 지표 분자/분모, 제외 사유를 표시합니다.
- Unknown은 유효 정답이며 Missing·미검수·비적용과 구분합니다. geometry 측정 불가는 별도 표시합니다.
- 공식 V5 조건 미충족이나 분모 0이면 N/A와 이유를 반환합니다.

모델 담당자가 임의 GT로 점수를 만들지 않습니다. 백엔드·데이터 파트가 사용할 reference와 공개 가능 범위는 별도로 확인해야 합니다. 아직 채점 결과를 수신하거나 팀원에게 전송하지 않았습니다.
