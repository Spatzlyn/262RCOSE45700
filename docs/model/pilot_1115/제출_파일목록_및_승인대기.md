# GitHub 제출 파일 및 승인 대기 작업

실제 저장소는 sw와 분리된 기존 로컬 저장소이며 현재 work/model-1115입니다. sw는 실험 작업 디렉터리이며 Git 저장소가 아닙니다. sw에서 git init하거나 새 저장소를 만들 필요가 없습니다. 로컬과 원격의 해당 branch는 확인 시 모두 7205ee4f9518dc75d30a05389e5e6977000a987a였습니다.

## 제출 제안

이 검토 폴더의 자료를 저장소 docs/model/pilot_1115/로 복사하는 방안을 제안합니다. 전체 파일별 목록과 SHA-256은 submission_inventory.json에 있습니다. 실제 복사·git add·Commit·Push·외부 발송은 사용자 승인 후에만 합니다.

- 한국어 실험 보고서, 백엔드 전달 안내, Notion 초안, 이 제출 계획.
- run_summary.csv, run_metadata.json, verification.json, handoff_manifest.json.
- backend_handoff의 전체 예측 JSON 6개, 원시 텍스트 6개, 디코딩 텍스트 6개.
- submission_inventory.json. 이 파일 자체는 자기참조 hash 대상에서 제외합니다.

예측은 모델이 생성한 파생 데이터입니다. 공개 저장소에 게시하기 전에 데이터 이용 조건 및 예측 내용의 공개 가능 여부를 팀이 확인해야 합니다. 이 자료 준비가 게시 승인을 뜻하지 않습니다.

## 제출 제외

16GB weights, models/, .venv 및 .venv-gemma, caches, private/Pilot/images, labels/GT/reference/C, 원 ZIP, 원본의 비공개 절대경로, 중국어 문서·기존 검증 보고서, 전체 kakao_dryrun, 실행 전의 오래된 preparation/error_analysis 상태 파일을 제외합니다. 초기 blocked 상태 기록은 당시 준비 스냅샷이므로 완료 결과와 섞어 올리지 않습니다.

## Git 상태와 보호

저장소 루트 .gitignore는 현재 없습니다. sw의 .gitignore는 별도 디렉터리여서 이 저장소를 보호하지 못합니다. 승인 시 models/, **/*.safetensors, private/, .venv*/, .uv-cache/, __pycache__/, .env 등을 제외하는 규칙을 추가할 수 있습니다. 아직 Git 설정이나 기존 ignore 파일을 변경하지 않았습니다. Ignore만 믿지 않고 승인된 파일만 명시 경로로 git add합니다.

현재 미추적 중국어 문서와 kakao_dryrun/은 기존 상태이며 건드리지 않았습니다. 강제 Push, reset, history 덮어쓰기, merge는 계획하지 않습니다.

## 승인 후 순서

1. branch와 index를 재확인합니다. 원격이 바뀌었으면 먼저 비교하고 기록합니다.
2. 승인된 파일만 저장소에 복사하고 hash를 비교합니다. 필요하면 승인 범위에 포함된 .gitignore를 추가합니다.
3. 명시 경로로만 git add 후 git diff --cached --name-only와 --check로 파일 목록·용량·내용을 확인합니다.
4. 커밋 메시지 제안은 docs(model): add verified Pilot6 Base results and handoff입니다.
5. 승인된 경우 origin work/model-1115에 일반 Push하고 원격 SHA를 확인합니다.
6. 새 commit과 문서 링크를 Notion 초안에 반영합니다. Notion 쓰기나 팀원 발송은 별도 승인 범위에서만 합니다.

본 문서는 작업 제안이며 Commit/Push 명령을 실행했다는 뜻이 아닙니다.
