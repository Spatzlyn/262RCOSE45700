# Annotation Guideline · pilot-guideline-0.4-draft

[팀 명세서](https://github.com/Spatzlyn/262RCOSE45700/blob/work/data-1115/docs/benchmark/Kakao_Road_VLM_Benchmark_Spec_Final.pdf) §2의 관계 정의를 적용합니다. 아래의 **Pilot 간소화 범위와 C 세부안은 팀 확정 규칙과 구분**합니다. 현재 검수 상태는 [README](README.md)에 기록합니다.

## 1. 판정 범위 및 객체·영역 목록

전방 단일 이미지(`F`)와 직진 주행 Intent를 기준으로 판정합니다. 단일 프레임만으로 차량의 주행/정차(Motion)나 미래 사건을 단정하지 않습니다.

| 구분 | 항목 | 처리 방법 |

- **반사상**: 유리창에 비친 차량은 실제 도로 객체의 점유 근거로 사용하지 않습니다. 원천 라벨은 보존하고 작업본에서 검수합니다.
- **가시 범위 원칙**: 새 박스를 추가할 때는 가려진 하체·차체를 상상해 늘리지 않고 실제로 보이는 범위만 잡습니다. `speed_bump`는 도로 시설물로 두고 `R1` 점유 대상에서 제외합니다.

## 2. 의미 역할·배치·가시성

- **`roadside` 배치**: 단일 이미지에서는 길가 차량이 주차 중인지 주행 중인지 단정할 수 없으므로 `roadside`를 정차 확정과 동일시하지 않습니다.
- **가림(`occluded`)과 잘림(`truncated`)**: 이미지 경계에 의해 잘린 경우(예: 하단 경계로 발이 잘린 보행자)와 다른 물체에 가려진 경우를 구분해 접지 확인 가능 여부를 판단합니다.

## 3. Driving Area `C` — 폭·깊이는 Pilot 잠정안

`C`는 진행 의도(Intent)와 도로 구조에 맞춰 지정하는 평가 영역입니다. **보행자나 차량을 피해 경계를 굽히거나 원하는 `R1` 결과에 맞춰 폭을 바꾸지 않습니다.**

Role_Data.pdf §4는 C의 폭·깊이를 Pilot 비교 후 확정하도록 합니다. 아래 안은 현재 작업을 위한 제안이며, 두 작성자의 경계 차이를 검토한 뒤 확정합니다.

| 항목 | 잠정 작성안 |
|---|---|
| **좌우 폭** | 중앙선이 없는 좁은 골목(공유도로)은 자차 차폭으로 좁게 자르지 않고 **양측 도로 경계(연석·배수로·노면 구분선)**를 따라 공유 공간을 지정합니다. 중앙선이 양방향 차로를 명확히 구분하고 자차가 우측 차로에 있으면 중앙선과 우측 경계 사이만 `C`로 지정합니다. |
| **부속 공간 제외** | 직진 Intent 시 `C` 옆의 상가 전면부, 측면 골목 내부, 개방형 주차 공간 내부는 `C`에 포함하지 않습니다. |
| **원단 깊이 및 가려진 경계** | 근단은 이미지 하단에서 시작하고, 원단은 도로 경계와 방향을 식별할 수 있는 마지막 구간에서 종료합니다. `01010324`처럼 근거리 차량에 의해 도로가 크게 가려진 경우 확인 가능한 범위까지만 `Draft`로 표시하고 근거 없는 먼 구간까지 연장하지 않습니다. |

## 4. Footprint와 R1 (점유)

Footprint는 발·바퀴 등 지면 접촉 부분의 위치입니다. **Box 하단 선분이 `C`와 겹친다는 이유만으로 `R1=P`를 부여하지 않습니다.**

- **판정 및 기록**: 모든 객체마다 점을 일일이 찍지 않고, 육안으로 발·타이어 접지점이 `C` 내부에 있는지 확인해 `Pilot/GT.csv`에 `P/A/U`와 근거 ID를 기록합니다.
- **가림·잘림**: 발이 이미지 하단에 잘렸거나(`01045907` 우측 하단 보행자 등) 차체에 가려 `C` 내외를 알 수 없으면 `U`로 남깁니다. 
- **원거리 차량**: 전방 원거리에 있더라도 확인 가능한 `C` 내부에 접지점이 들어가면 공간 점유 `R1=P`로 기록합니다. 점유 판정과 대응은 구분합니다.
- **장면 집계**: 명확한 `P` 근거가 하나라도 있으면 장면 `R1=P`, `P`가 없고 미해결 대상이 있으면 `U`, 모두 확인해 해당하지 않으면 `A`입니다.

## 5. R2·R3·R4 판정 기준

| 관계 | `P` 판정 기준 | 주의 및 제외 기준 |
|---|---|---|
| **R2 (출입구)** | `C`와 연결된 출입구(골목 입구, 주차장·차고 입구, 상가 출입문, 도로로 열린 저층 개방형 주차 공간 입구) 안 또는 경계에 **가시 Actor(사람·차량 등)**의 접지 위치가 존재 | 단순 상가 벽면·쇼윈도·광고판 옆 보행이나 적치물만 있는 경우는 제외. 보이는 Actor 중 출입구 주변 대상이 없으면 `R2=A`. **보이는 Actor의 접지 위치 또는 출입구 경계가 불명확해 관계를 판단할 수 없으면 `R2=U`**. 숨은 Actor의 가능성은 R2 근거로 사용하지 않으며, 가림은 R3 기준으로 별도 판정 |
| **R3 (시야 가림)** | 객체가 자차 시점에서 **전방 진행 판단에 필요한 주행 노면이나 출입구 시야**를 가림 | 앞차가 더 앞선 다른 차량의 차체 일부만 가린 경우는 제외. 가려진 뒤쪽에 사람이 있을 것이라 추측하지 않고, 가려진 영역 자체가 진행 판단에 필요한지 확인 |
| **R4 (통행 제한)** | 길가 차량·적치물·공사 시설물 등의 배치로 해당 `C` 구간의 **실제 가용 통행 폭이 물리적으로 좁아짐** (통과 가능하더라도 `P` 가능) | 단순히 차량이 보인다는 이유만으로 `P` 부여 금지. **진입금지·일방통행 등 표지판 문구 자체만으로는 `R4=P`를 주지 않음**(표지판·장애물 본체가 노면을 침범한 경우만 해당) |

- **길가 차량의 R1·R4 동시 성립 (팀 명세서 PDF §2.2)**: 길가 차량의 바퀴 접지점이 `C` 내부로 들어와 있고 동시에 통행 폭을 좁히면 **동일 차량 ID로 `R1=P`와 `R4=P`를 함께 기록**할 수 있습니다.

## 6. Sidewalk · 횡단보도 구분

- **횡단보도 제외**: **횡단보도는 `Sidewalk(보도)`의 근거로 사용할 수 없습니다.**
- **단차 보행 공간과 연속 보도 구분**: 건물 앞에만 연석·난간으로 좁게 높여 만든 공간은 국소 단차 보행 공간으로 구분하며, 양측에 연속 설치된 표준 보도와 혼동하지 않습니다.
