## 기존 6장: 처리 및 추가 확인
- 001 전방 A·측방 P 및 R3=P에 동의. 점유 상태 P는 유지하되 태문님의 5개 근거 객체 모두 포함 여부는 별도 검수.
- 002 측방 P·병목 P, 003 측방 A·연결부 이용자 A, 004 연결부 이용자 A·측방 P·병목 P, 006 연결부 P·이용자 P·측방 A·병목 A 동의.
- 005 전방 A·측방 A·병목 A 동의. 연결부 이용자는 A 제안. 259504가 주차 공간에 존재한다는 이유만으로 연결부 이용자로 인정하지 않음. 실제 접지가 C1 내부/경계인지 확인 요청. 불분명하면 U.
- 001·002 측방 P의 누락 Region ID를 보완하되 숨은 영역 좌표는 null 유지.

## 공통 Guideline 보완
- 연결부 이용자는 연결부 내부/경계에 실제 접지가 있는 Actor이다. 정차 상태도 위치 조건을 충족하면 P이지만 단지 인접 주차장에 있는 차량, Box 중첩만으로 P 판정하지 않는다. R2=A→NA, R2=U→U.
- 병목은 인접 구간에 비해 공간 폭이 국소적으로 줄어드는 상태. 통과를 못할 정도인지와 별개. 비교 구간·물리적 원인이 식별되는 경우 P; 폭 변화 불명확 U.
- 가림은 진행 판단에 필요한 전방 또는 측방 공간이 물리적으로 가려지는지 기록. 숨은 범위의 정밀 Polygon은 그리지 않고, 확인 가능한 근거 Region/객체와 미측정 geometry를 기록.
- 사유가 없는 A는 JSON 필수 reason에 `-` 허용. 장면별 시간은 미기록(null).
