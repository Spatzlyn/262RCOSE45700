# Pilot 6건 Draft GT 대조

최신 자료는 [데이터 인수인계](../../../data_handoff/README.md)에 있다. 아래는 공통 6장의 합의 전 대조 기록이다.

[pilot6_annotations.jsonl](pilot6_annotations.jsonl)은 공통 6장의 AI 초안을 원본 사진과 대조해 수정한 Draft GT다. [기존 Draft GT](../../../data_v11/pilot6_v11_draft.jsonl)와 비교한 결과, R1–R3 판정은 18개 중 14개가 일치했다. 공식 채점에는 두 사람이 합의한 Reviewed GT를 사용한다.

## 관계별 대조

| 관계 | 일치 / 전체 | 판정이 다른 문항 |
|---|---:|---|
| R1 | 6 / 6 | — |
| R2 | 5 / 6 | 006 |
| R3 | 3 / 6 | 001, 003, 005 |
| 합계 | 14 / 18 | |

005의 R1은 A에서 U로 수정해 두 검토본의 판정이 일치했다. 차량 259504의 바퀴 접지점과 D의 왼쪽 경계가 흐릿해 접지점이 D 안에 있는지 구분하기 어렵다.

| 문항 | 관계 | 이번 검토 | 기존 검토 | 판단 근거 |
|---|---|---|---|---|
| 001 | R3 | P | U | 상가 간판과 건물 배치로 옆 통로의 방향을 짐작할 수 있다. 주차 차량이 그쪽 시야를 가린다. |
| 003 | R3 | A | U | T자 교차로에서 건물 모서리 너머가 보이지 않는 것만으로는 R3에 해당한다고 보기 어렵다. |
| 005 | R3 | A | P | 사진에서 왼쪽 주차 차량 뒤로 별도 공간이 보이지 않는다. |
| 006 | R2 | P | U | 왼쪽 나무 가림막 끝에서 입구가 D와 맞닿는 지점을 `reg_conn_1`로 표시했다. |

세부 관찰 4개 필드는 별도로 비교했다. 연결부 이용자는 2/6건, 전방 가림은 4/6건, 측방 가림은 0/6건, 병목은 2/6건이 일치했다. 002와 004는 R1–R3가 모두 일치하지만 측방 가림과 병목 판정은 다르다.



## 입력 및 비교 방법

1. 두 JSONL에서 `item_id`가 같은 행을 연결하고, 6건 모두 `image_sha256`이 같은지 확인했다.
2. 각 문항의 `relations.R1–R3`와 `context` 4개 필드에서 `state`를 비교했다. P/A/U 값이 같은 경우만 일치로 집계했다.
3. 객체 ID, 영역 좌표, 판단 근거 문장은 일치율 계산에서 제외했다. 같은 판정에서도 근거 객체가 다를 수 있다. 예를 들어 001 R1은 양쪽 모두 P지만, 기존 검토본은 보행자 `204922` 한 명을, 이번 검토본은 해당 보행자를 포함한 다섯 객체를 근거로 기록했다.
